# 캐릭터 시트 제작 지침서 (코드 이전용 정리본)

> 원본: Claude 문서 「프리다이빙리조트 메타버스 · 캐릭터 시트 제작 지침서」 v2 (2026-11-23)
> 이 정리본은 v2 이후(11-24~11-27)에 바뀐 결정을 반영했다. **원본과 다르면 이 문서가 우선이다.**
> 수치(픽셀·좌표)는 원본 v2 기준이며, 실제 파일과 다르면 실측값으로 고친 뒤 고정한다.

## 1. 핵심 원칙

1. **기준 그림 하나에서 시작한다.** 빨간 단발 여자 캐릭터 정면(선명하게 다시 그린 버전)이 모든 동작의 기준이다.
2. **캐릭터 전체를 한 번에 받는다.** 머리·슈트를 포함한 완성 캐릭터로 동작을 받는다. (녹색 기본 몸 + 머리 분리 + 코드 의상 방식, 부위를 잘라 관절을 움직이는 방식은 중단)
3. **발 기준점은 절대 움직이지 않는다.** 모든 프레임에서 발바닥 중앙이 같은 좌표.
4. **겹치지 않는 최소 동작만 만든다.** 같은 동작을 중복 제작하지 않는다.
5. **동작은 하나씩.** 한 번에 여러 동작을 요청하거나 반영하지 않는다.
6. **AI에 수정 요청하지 않는다.** 마음에 안 들면 새로 생성한다. 정리는 코드가 매번 똑같이 한다.

## 2. 그림체

- 2등신 치비, 큰 눈, 굵고 균일한 외곽선(#1A1A1A)
- 플랫 채색 + 그림자 1단계(빛은 왼쪽 위, 그림자는 오른쪽·아래). 그라데이션 금지
- 헤어는 광택 1단계 허용(짧은 사선 2~4개, 방향·프레임마다 같은 위치)
- 몸은 근육형 하나로 통일
- 질감 예외: 비키니 등 실제 상품은 질감을 표현한다
- 휴대폰에서 안 보이는 작은 장식(작은 로고, 가는 줄)은 그리지 않는다

## 3. 캔버스 규격 (v2 수치)

| 항목 | 생성(4배) | 작업(2배) | 게임(1배) |
| --- | --- | --- | --- |
| 한 칸 | 1024 × 1024 | 256 × 256 | 128 × 128 |
| 발 기준점 | x 512, y 928 | x 128, y 232 | x 64, y 116 |
| 머리끝 | y 160 | y 40 | y 20 |
| 턱 | y 536 | y 134 | y 67 |
| 캐릭터 전체 키 | 768 | 192 | 96 |

- 목 없음. 머리가 몸통 위를 약간 덮는다(작업 크기 10px)
- 바닥 그림자는 코드가 그린다(발 기준점 중심 타원, 검정 30% 투명)

## 4. 동작 목록 (확정, 모두 4프레임)

| 동작 | 방향 | 비고 |
| --- | --- | --- |
| 걷기 | 앞·뒤·좌·우 | 서기는 걷기 1프레임으로 대체 |
| 앉기 | 앞·뒤 | 일반 앉기는 **양반다리** |
| 인사 | 정면 | |
| 아임오케이 | 정면 | |
| 점프 | 정면 | |

- 받는 형식: 동작마다 **2×2 스프라이트 시트 1장(4프레임)**
- 배경: 없음(투명) 또는 **마젠타**
- 걷기 8프레임은 쓰지 않는다(4프레임과 차이 적음)
- 다리 뻗고 앉기(요가장 앉기)는 쓰지 않는다. 요가 매트도 일반 앉기(양반다리)로 통일 (2026-11-28)
- 몸 비율 기준: 시연의 기본 4프레임 걷기 빨간 단발 몸(짧고 동글한 몸)

## 5. 슈트·의상 규칙

- 기본 렌탈 슈트: **회색 슈트, 색 변경 가능**(`hair3/body_suitg.webp`). 음영 최소화
- 시연 캐릭터가 입은 무늬 슈트(`hair3/body_suit.webp`)도 렌탈용
- **뒷모습**: 라인 없음, 손가락·발가락 없음
- 모든 슈트·의상은 **앉은 버전까지 포함해 모든 동작**을 만든다
- 새 슈트·수영복은 실제 사진 2~3장을 첨부해 제작. 새로 추가하는 판매용 슈트는 단일 색상(색 변경 없음), 질감만 다를 수 있음 (기본 렌탈 회색 슈트는 예외로 색 변경 가능)
- 꾸미기 장비는 남녀 구분(비키니·스프링슈트 등은 여성만)

## 6. 남자 캐릭터

- 기본 머리: 모히칸
- 동작 시트는 여자 시트를 그대로 쓰고 **머리만 남자 머리로 교체**

## 7. 헤어·피부 색 변환 (크로마키)

| 영역 | 기본색 | 그림자 | 광택 | 변환 대상 |
| --- | --- | --- | --- | --- |
| 피부 | #FF00FF | #B300B3 | – | 피부톤 5종 |
| 머리카락 | #00FF00 | #00B300 | #B3FFB3 | 머리색 10종 |
| 의상 메인 | #00FFFF | #00B3B3 | – | 슈트·장비 컬러 |
| 의상 포인트 | #FFFF00 | #B3B300 | – | 라인·로고 배색 |

- 크로마키 영역은 안티에일리어싱 끄기(테두리에 분홍·녹색이 남지 않게)
- 헤어·피부 꾸미기는 **공유 몸 + 머리만 겹치는 방식**(`hair3/`)
- 마젠타 배경을 쓸 경우 피부 크로마키(#FF00FF)와 겹치지 않는지 확인한다

## 8. 받은 그림 처리 (코드가 자동으로)

1. 배경 제거 → 투명
2. 키를 기준 높이에 맞춰 크기 통일
3. 발 기준점에 자동 정렬
4. 색을 단색 + 그림자 1단계로 정리, 번진 테두리 제거
5. 외곽선 두께 통일
6. 작업 크기·게임 크기 두 벌 저장 + 격자에 올린 검수 이미지 1장

사람이 할 일은 그림 받기와 검수 이미지 합격/불합격 판단뿐이다.

## 9. 검수 체크리스트

- [ ] 모든 칸의 발바닥 중앙이 기준점 위에 있다
- [ ] 머리 크기가 기준과 같다
- [ ] 외곽선 두께가 같다
- [ ] 실제 이동 속도로 재생했을 때 머리가 흔들리지 않는다
- [ ] 머리색·피부톤을 바꿔도 테두리에 다른 색이 남지 않는다
- [ ] 휴대폰 화면에서 동작이 구분된다
